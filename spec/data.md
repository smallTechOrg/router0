# Data: Zer0 Router

## Entities

### users

Registered users of the platform.

| Column | Type | Constraints | Description |
|--------|------|------------|-------------|
| `id` | UUID | PK, default gen_random_uuid() | |
| `email` | TEXT | UNIQUE NOT NULL | Login identifier |
| `password_hash` | TEXT | NOT NULL | bcrypt(cost=12) of password |
| `zer0_key_hash` | TEXT | NOT NULL | bcrypt(cost=12) of the full zer0:sk-xxx key |
| `zer0_key_prefix` | TEXT | NOT NULL | First 12 chars after `zer0:sk-` (non-secret; used for fast lookup) |
| `role` | TEXT | NOT NULL DEFAULT 'user' | `user` or `admin` |
| `status` | TEXT | NOT NULL DEFAULT 'active' | `pending` / `active` / `disabled` |
| `invited_by` | UUID | FK users(id), NULLABLE | Admin who issued the invite |
| `created_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |
| `updated_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |

Indexes: `users_email_idx` on `(email)`, `users_zer0_key_prefix_idx` on `(zer0_key_prefix)`.

### invites

Single-use invite tokens issued by admins.

| Column | Type | Constraints | Description |
|--------|------|------------|-------------|
| `id` | UUID | PK | |
| `email` | TEXT | NOT NULL | Intended recipient (informational; not enforced on registration) |
| `token` | TEXT | UNIQUE NOT NULL | Opaque UUID used in registration URL |
| `invited_by` | UUID | FK users(id) NOT NULL | Admin who created the invite |
| `accepted_at` | TIMESTAMPTZ | NULLABLE | Set when registration completes |
| `expires_at` | TIMESTAMPTZ | NOT NULL | 7 days from created_at |

### provider_keys

Encrypted LLM provider API keys belonging to users.

| Column | Type | Constraints | Description |
|--------|------|------------|-------------|
| `id` | UUID | PK | |
| `user_id` | UUID | FK users(id) NOT NULL | Owning user |
| `provider` | TEXT | NOT NULL | `google` / `groq` / `openrouter` / `nvidia` / `together` / `baseten` |
| `label` | TEXT | NOT NULL DEFAULT '' | User-supplied friendly name |
| `key_hint` | TEXT | NOT NULL | First 8 chars of raw key + `…` (stored at write time, never re-derived) |
| `key_ciphertext` | BYTEA | NOT NULL | AES-256-GCM encrypted raw key |
| `key_nonce` | BYTEA | NOT NULL | 12-byte random GCM nonce (unique per key record) |
| `model_id` | TEXT | NULLABLE | Baseten only: deployment model ID |
| `status` | TEXT | NOT NULL DEFAULT 'active' | `active` / `error` / `disabled` |
| `last_tested_at` | TIMESTAMPTZ | NULLABLE | Timestamp of last manual test |
| `last_test_result` | TEXT | NULLABLE | `ok` / `error:<provider_error_code>` |
| `created_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |
| `updated_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |

Indexes: `provider_keys_user_id_idx` on `(user_id)`, `provider_keys_user_provider_idx` on `(user_id, provider)`.

Soft-delete only: `status = 'disabled'`. No hard DELETE.

### request_metadata

Per-request metadata (no prompt content stored).

| Column | Type | Constraints | Description |
|--------|------|------------|-------------|
| `id` | UUID | PK | |
| `user_id` | UUID | FK users(id) NOT NULL | |
| `zer0_request_id` | TEXT | UNIQUE NOT NULL | UUID generated by router for this request |
| `provider` | TEXT | NOT NULL | Provider that served the request |
| `model` | TEXT | NOT NULL | Model used |
| `provider_key_id` | UUID | FK provider_keys(id) NULLABLE | Which key was used (nullable if key was deleted) |
| `pool` | TEXT | NOT NULL | `active` or `common` |
| `input_tokens` | INT | NOT NULL DEFAULT 0 | |
| `output_tokens` | INT | NOT NULL DEFAULT 0 | |
| `latency_ms` | INT | NOT NULL DEFAULT 0 | Wall-clock ms from request start to last byte |
| `estimated_cost_usd` | NUMERIC(14, 8) | NOT NULL DEFAULT 0 | Estimated cost in USD |
| `status` | TEXT | NOT NULL | `success` / `error` / `hedged` |
| `retry_count` | INT | NOT NULL DEFAULT 0 | 0=no retry, 1=sequential retry, 2=hedge |
| `error_class` | TEXT | NULLABLE | `ProviderError.Class` value (null on success) |
| `created_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |

Indexes: `request_metadata_user_id_created_at_idx` on `(user_id, created_at DESC)`, `request_metadata_created_at_idx` on `(created_at DESC)`.

Retention: rows are kept indefinitely in Phase 1. Phase 2 adds a configurable TTL-based archival job.

### pool_scores

Persisted pool membership and score snapshots per user per combo. Redis is the live source of truth; this table is updated by the background re-scoring goroutine every 5 minutes for durability and dashboard queries.

| Column | Type | Constraints | Description |
|--------|------|------------|-------------|
| `id` | UUID | PK | |
| `user_id` | UUID | FK users(id) NOT NULL | |
| `provider` | TEXT | NOT NULL | |
| `model` | TEXT | NOT NULL | |
| `provider_key_id` | UUID | FK provider_keys(id) NOT NULL | |
| `pool` | TEXT | NOT NULL | `active` or `common` |
| `score` | NUMERIC(6, 4) | NOT NULL DEFAULT 0 | Weighted score [0, 1] |
| `p95_latency_ms` | INT | NOT NULL DEFAULT 0 | |
| `error_rate_1h` | NUMERIC(6, 4) | NOT NULL DEFAULT 0 | |
| `cost_per_token` | NUMERIC(14, 10) | NOT NULL DEFAULT 0 | USD per token |
| `last_health_check_at` | TIMESTAMPTZ | NULLABLE | |
| `updated_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |

UNIQUE constraint on `(user_id, provider, model, provider_key_id)`.

Indexes: `pool_scores_user_id_idx` on `(user_id)`.

## Redis Key Schema

| Key Pattern | Type | Value | TTL |
|-------------|------|-------|-----|
| `pool:{user_id}:active` | Sorted set | Members = `{provider}:{model}:{key_id}`, score = routing score | No TTL (managed by re-scorer) |
| `pool:{user_id}:common` | Sorted set | Same | No TTL |
| `rl:{user_id}:{provider}:{model}:minute` | String | Integer request count | Expires at top of next minute |
| `rl:{user_id}:{provider}:{model}:hour` | String | Integer request count | Expires at top of next hour |
| `rl:{user_id}:{provider}:{model}:day` | String | Integer request count | Expires at UTC midnight |
| `rl:{user_id}:{provider}:{model}:rem:minute` | String | Remaining requests (from provider header) | Expires at top of next minute |
| `rl:{user_id}:{provider}:{model}:rem:hour` | String | Remaining requests | Expires at top of next hour |
| `rl:{user_id}:{provider}:{model}:rem:day` | String | Remaining requests | Expires at UTC midnight |
| `metrics:{user_id}:{provider}:{model}` | Hash | fields: `req_5m`, `err_5m`, `req_1h`, `err_1h`, `p95_ms`, `last_at` | No TTL |
| `health:{provider}:{model}` | Hash | fields: `status` (`ok`/`error`), `latency_ms`, `checked_at` | 30 min |
| `throttle:{provider}` | String | `"1"` | 5 min (provider-level throttle cooldown) |
| `probe_lock:{provider}:{model}:{key_id}` | String | `"1"` | Duration of probe interval (prevents concurrent probes) |
| `bandit:{user_id}:{provider}:{model}` | Hash | fields: `alpha`, `beta` | No TTL (Phase 2) |


## Data Lifecycle

### User account
Created at registration (status=active). Admin sets status=disabled to ban. Records are never deleted (soft-disable only).

### Invite
Created by admin. Consumed (accepted_at set) at registration. Expired invites are ignored by the application but not purged. An admin may create a replacement.

### Provider key
Created by user. Soft-deleted (status=disabled) on user request or admin action. Encryption key (`AES_KEY`) rotation requires re-encrypting all ciphertexts — a maintenance operation documented in the operator runbook, not in the application UI.

### Request metadata
Written asynchronously after each request completes (success or failure). Never updated after INSERT. Never contains prompt content.

### Pool score
Upserted by the background re-scoring goroutine every 5 minutes. The `updated_at` timestamp is how the dashboard knows when data is stale.
